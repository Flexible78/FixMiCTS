# FixMiCTS — краткая инструкция

- [Страница релиза и контрольные суммы SHA256](https://github.com/Flexible78/FixMiCTS/releases/tag/v1.3.1)

APK находится в разделе **Assets** на странице релиза, а не в списке исходников. FixMiCTS — отдельное приложение для восстановления настроек; оригинальный MiCTS и Vivid N.G. устанавливаются отдельно.

Автор и сопровождающий проекта — Flexible78. Разработка и аудит выполнялись с помощью ИИ-инструментов; название проекта — FixMiCTS.

Предварительный неофициальный workaround, не замена MiCTS и не исправление самой прошивки. На Vivo X100 Ultra / OriginOS 16 подтверждены восстановление Google VIS и автоматический reboot-возврат службы доступности Vivid N.G.; три холодных теста и многодневная стабильность пока не подтверждены.

Что чинит версия 1.3.1:

- **MiCTS / Google VIS** — возвращает `voice_interaction_service` для Google после перезагрузки.
- **Vivid N.G.** (`com.ivianuu.oneplusgestures`) — возвращает службу специальных возможностей («рычажок» Enabled) только дополнением списка, затем best-effort включает жесты. Диалог подтверждения вручную не нужен.

1. Взять подписанный APK и SHA256 из Releases, проверить контрольную сумму.
2. Подключить разрешённый ADB; положить APK и его .sha256 рядом с INSTALL_TO_VIVO.cmd и запустить. Скрипт ограничен проверенной моделью V2366HA и user 0.
3. Включить Автозапуск только Fix MiCTS, проверить GRANTED, FIX NOW, настоящий жест MiCTS и жесты Vivid.
4. Проверку после ручного выключения/включения проводить до открытия Fix MiCTS, FIX NOW или переключения помощника.

WRITE_SECURE_SETTINGS — мощное разрешение: выдавайте его только доверенному APK после ознакомления с исходниками. Успешная запись настройки не доказывает подключение службы. Резерв — FIX NOW; чтение диагностики — DIAGNOSE.cmd (показывает и состояние доступности Vivid). FIX_FROM_PC.cmd изменяет настройки по явному запуску и тоже поднимает Vivid.

Исходники собираются BUILD_APK.cmd с JDK 17/21. Новый checkout создаёт собственную подпись: такой APK не обновит релиз с другой подписью. Ключ и пароль никогда не публикуются. Gradle/Studio и публикация Google Play не проверены.

BATTERY_AUDIT.cmd только читает данные; сохраняет временные отчёты с неполным маскированием. Перед передачей проверяйте их вручную. Никакого массового удаления, отключения, сброса батарейной истории или постоянного фонового сервиса нет.
