# FixMiCTS — краткая инструкция

Предварительный неофициальный workaround, не замена MiCTS и не исправление самой прошивки. Подтверждён один обычный автоматический reboot на Vivo X100 Ultra / OriginOS 16; три холодных теста и многодневная стабильность пока не подтверждены.

1. Взять подписанный APK и SHA256 из Releases, проверить контрольную сумму.
2. Подключить разрешённый ADB; положить APK и его .sha256 рядом с INSTALL_TO_VIVO.cmd и запустить. Скрипт ограничен проверенной моделью V2366HA и user 0.
3. Включить Автозапуск только Fix MiCTS, проверить GRANTED, FIX NOW и настоящий жест MiCTS.
4. Проверку после ручного выключения/включения проводить до открытия Fix MiCTS, FIX NOW или переключения помощника.

WRITE_SECURE_SETTINGS — мощное разрешение: выдавайте его только доверенному APK после ознакомления с исходниками. Успешная запись настройки не доказывает подключение службы. Резерв — FIX NOW; чтение диагностики — DIAGNOSE.cmd. FIX_FROM_PC.cmd изменяет настройку по явному запуску.

Исходники собираются BUILD_APK.cmd с JDK 17/21. Новый checkout создаёт собственную подпись: такой APK не обновит релиз с другой подписью. Ключ и пароль никогда не публикуются. Gradle/Studio и публикация Google Play не проверены.

BATTERY_AUDIT.cmd только читает данные; сохраняет временные отчёты с неполным маскированием. Перед передачей проверяйте их вручную. Никакого массового удаления, отключения, сброса батарейной истории или постоянного фонового сервиса нет.
